DESCRIPTION
No editor. Just Claude.

People keep asking how I edit my videos. One big "make it viral" prompt doesn't work. So last weekend I built my own AI editor that runs on my Claude Code credits. This is the exact workflow:

→ record one take
→ clean up the transcript (my skill file does this)
→ plan the edit from presets
→ pick animations from open-source GitHub libraries
→ build every scene in code with HyperFrames
→ render, then check it automatically

It now edits a video in about 15–20 minutes (sometimes 10), and it gets faster every time because assets, animations and effects are saved and reused.

Want the repo? Comment "repo" and I'll share it. Fair warning: it's tuned for my talking-head tech style, so it may not fit other genres yet.
